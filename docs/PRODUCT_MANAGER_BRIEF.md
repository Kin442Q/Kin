# KinderCRM — бриф для продакт-менеджера

**Дата:** 18 мая 2026  
**Продукт:** KinderCRM (веб + мобильное приложение)  
**Версия кодовой базы:** 2.0  
**Аудитория документа:** Product Manager, основатели, инвесторы

---

## 1. Краткое резюме

**KinderCRM** — B2B SaaS / on-premise CRM/ERP для частных детских садов и (расширение) школ: учёт детей и групп, посещаемость, оплаты и расходы, **аналитика прибыльности по группам**, мобильные сценарии для воспитателей и родителей, учёт рабочего времени, дневник, школьный журнал.

| Параметр | Оценка |
|----------|--------|
| Зрелость продукта (функции) | **~70%** — сильный MVP+, не полный enterprise |
| Готовность к коммерции (продажи SaaS) | **~35%** — нет биллинга, онбординга, App Store |
| Техническая база | **Высокая** — NestJS, Prisma, PostgreSQL, Redis, Expo |
| Уникальность на рынке СНГ | **Средняя+** — финансы по группам + мобайл + time tracking |

## 2. Вердикт: рентабелен ли продукт?

### 2.1. Два разных смысла «рентабельности»

| Вопрос | Ответ |
|--------|--------|
| **Помогает ли продукт садику понять, прибылен ли он?** | **Да.** Встроенная P&L-логика, аналитика, рейтинг групп — это ядро ценности. |
| **Рентабелен ли KinderCRM как бизнес (SaaS) сегодня?** | **Нет, пока не запущены продажи и монетизация.** Это зрелый прототип / pre-revenue продукт. |
| **Может ли стать рентабельным?** | **Да, при условии** фокуса на 1–2 рынка, 10–30 платящих учреждений и доработки коммерческого контура (см. §6). |

### 2.2. Итоговый вердикт (одной фразой)

> **Продукт технически и по ценности для клиента — перспективный; как коммерческий SaaS сейчас не рентабелен, потому что нет выручки, тарифов, воронки продаж и завершённого mobile release. Окупаемость возможна при целевой модели ~$30–80/мес за садик и 50+ клиентов в течение 12–18 месяцев после запуска продаж.**

### 2.3. Условная экономика (для планирования)

Ориентир для частного сада в СНГ (Таджикистан / Узбекистан / Кыргызстан / регионы РФ):

| Статья | Оценка / мес. |
|--------|----------------|
| Инфра (Railway/VPS, Postgres, Redis) | $15–50 на старт, $5–15 на клиента при multi-tenant |
| Поддержка (1 человек на 30–50 садов) | доля ФОТ |
| **Цена для клиента (рыночный коридор)** | **$25–60 / мес** или **300–800 сом/сомони** локально |
| **Точка безубыточности SaaS** (только инфра + мин. маркетинг) | **~25–40 платящих садов** при ARPU $40 |
| **Устойчивая прибыль** | **80–150 клиентов** + upsell (SMS, терминалы, white-label) |

*Цифры — порядок величины для roadmap, не финмодель.*

### 3.2. Бэкенд (NestJS)

- JWT access + refresh, RBAC (SUPER_ADMIN, ADMIN, TEACHER, PARENT)
- Модули: auth, students, groups, finance, analytics, attendance, payments, expenses, menu, meetings, notifications, **telegram**, **time-tracking** (геофенс, терминал Hikvision/ZKTeco), **diary**, **school**, parent API
- Redis, BullMQ (очереди), Swagger, throttling, audit log в схеме
- **Деплой:** production URL на Railway (мобайл указывает на `kin-production-b330.up.railway.app`)
- **Тесты:** ~10 unit-спеков на сервере (auth, payments, attendance и др.)

### 3.3. Мобильное приложение (Expo)

| Роль | Готово | В работе / заглушка |
|------|--------|---------------------|
| Учитель (сад) | Check-in/out, Face ID, посещаемость, дневник | — |
| Учитель (школа) | Журнал, ДЗ, посещаемость | — |
| Родитель | Главная, оценки (школа) | Расписание, оплата — placeholder |
| Админ (мобайл) | Сводка, группы, оплаты | Расходы, встречи — частично |
| Релиз | Expo Go | **Нет EAS / App Store / Play Store** |
| Push | — | **Не подключены** |
| Чат родитель–сад | — | **Удалён / не реализован** |

### 3.4. Архитектурные сильные стороны

1. **Прибыльность по группам** — редкая связка «операционка + P&L» в нише частных садов СНГ.  
2. **Multi-tenant** в Prisma — готовность к SaaS без переписывания.  
3. **Два типа учреждения** (KINDERGARTEN / SCHOOL) — удвоение рынка.  
4. **Time tracking + геофенс + терминал** — снижение «фиктивных» отметок, контроль ФОТ.  
5. **Telegram** — канал уведомлений, привычный для региона.

### 3.5. Критические пробелы (блокеры коммерции)

| Пробел | Риск |
|--------|------|
| Нет подписки / биллинга для **вашего** SaaS | Невозможно считать MRR |
| Демо-режим (localStorage) параллельно с API | Путаница при демо инвесторам |
| Mobile не в сторах | Родители не скачают «Expo Go» |
| Часть parent-flow на мобайле — заглушки | Низкий retention родителей |
| Нет онбординга «садик за 15 минут» | Долгий time-to-value |
| Credentials в README (см. §8) | **Критичный security-риск** |
| Нет локализации EN / юридических документов | Ограничение экспансии |

## 4. Конкурентный контекст (СНГ)

| Класс решений | Примеры | Сильные стороны конкурентов | Где мы сильнее |
|---------------|---------|----------------------------|----------------|

**Позиционирование:** не «ещё одна CRM», а **«финансово прозрачный садик + родители в телефоне»**.

## 5. Целевые сегменты и ICP

| Сегмент | Размер | Боль | Готовность платить |
|---------|--------|------|-------------------|
| Частный садик 2–5 групп | 15–80 детей | Долги родителей, не видят прибыль по группам | Средняя |
| Сеть 2–10 филиалов | 100–500 детей | Консолидированная отчётность | Высокая |
| Частная начальная школа | классы | Журнал, ДЗ, родители | Средняя (конкуренция выше) |
| Репетиторские центры (adjacent) | малые группы | Расписание + оплата | Низкая–средняя |

**ICP для первых 20 клиентов:** владелец частного сада, 2–4 группы, уже ведёт оплаты в Excel, активен в Telegram, город 50k–500k населения.

## 6. Roadmap приоритетов (продукт × коммерция)

### Фаза 0 — «Можно продавать» (4–8 недель)

1. Убрать утечки секретов из репозитория; ротация ключей Railway/JWT.  
2. Единый production-режим: веб всегда на API, демо только на отдельном tenant.  
3. Довести mobile parent: **расписание + оплаты** (не placeholder).  
4. **EAS Build** → TestFlight / Internal testing → Play Console.  
5. Лендинг + 3 тарифа + заявка / оплата (хотя бы перевод + ручная активация).  
6. Онбординг: создать садик → группы → импорт детей (CSV).

### Фаза 1 — «Удержание» (2–3 мес.)

7. Push-уведомления (оплата просрочена, ребёнок пришёл).  
8. Telegram-бот: напоминания родителям, рассылка меню.  
9. Онлайн-оплата (локальный эквайринг / Payme / Click / humo — по рынку).  
10. Отчёты PDF для владельца (месяц, налоги).  

### Фаза 2 — «Масштаб» (3–6 мес.)

11. Биллинг SaaS (Stripe / Paddle или локальный).  
12. Супер-админ панель: все tenants, метрики MRR, churn.  
13. Чат родитель–воспитатель (модерация, шаблоны).  
14. Маркетплейс доп. занятий (комиссия).  
15. Интеграция 1С / бухгалтерия (экспорт).
