# Дизайн-система «Мактаби ман» (мобильное приложение)

Этот файл описывает дизайн **так, как он реализован в коде**, и правила, по которым пишутся новые экраны. Если
правишь внешний вид, правь и этот файл. Исходные макеты (дизайн-борды) в репозиторий не входят: все значения ниже
взяты из `src/theme/`, `src/components/` и экранов.

Палитра называется «Помир»: бирюзовый и коралловый на мягком «закате» (персиковое небо, горы на заставке и входе).
Есть светлая и тёмная тема.

---

## 1. Цвет

Все цвета берутся из токенов `colors.*` (`src/theme/colors.ts`). Значения в коде не пишутся.

| Токен | Светлая | Тёмная | Где |
|---|---|---|---|
| `bg` | `#FFE4D6` | `#0A2A2C` | основа экрана под фоном-закатом |
| `surface` | белый 56% | белый 7% | стеклянная карточка |
| `surfaceSolid` | `#FFFFFF` | `#123C3E` | окна, поля, панель, выбранная вкладка (светлая) |
| `surfaceAlt` | тёмный 6% | белый 7% | чипы, неактивные кнопки, дорожки |
| `primary` / `primaryDeep` | `#0D7A7C` / `#075B5D` | `#139A9C` / `#7FE0DB` | бренд, главные кнопки, ссылки |
| `primarySoft` / `primaryGhost` | бирюза 14% / 8% | бирюза 18% / 10% | подложки значков, плашки |
| `coral` | `#FF8A65` | `#FF8A65` | второй акцент: бейджи, «сейчас», непрочитанное |
| `blue` / `yellow` / `rose` / `lilac` (+ `Deep`, `Soft`) | см. файл | см. файл | цветовые акценты статусов и плиток |
| `text` / `textMid` / `muted` | `#10282A` / `#2C4749` / `#4A6466` | `#F2F7F6` / `#A9C2C3` / `#8FA9AA` | основной / второй / подписи |
| `border` / `borderSoft` / `glassBorder` | тёмный 14% / 8%, белый 85% | белый 16% / 10% / 14% | рамки |
| `danger` | `#C0392B` | `#FF7A6B` | ошибки, удаление |
| `onPrimary` | `#FFFFFF` | `#FFFFFF` | текст и значки на залитом бирюзовом |

**Правила**
- Только токены. Жёсткие `#fff`, `rgba(255,255,255,…)`, `#10282A` в стилях ломают тёмную тему: подпись становится
  светлой на белом (так было с вкладками «ДЗ», живым уроком, карточкой оплаты). Допустимо только на заведомо
  цветных подложках (градиентная карточка «Сейчас», значки на коралловом).
- Состояния (успех/внимание/ошибка) берутся парами `xxxSoft` (фон) + `xxxDeep` (текст).
- Контраст: основной текст `text` на `surface`/`bg`; `muted` только для вторичных подписей (даты, подсказки).

## 2. Типографика

Шрифты лежат в `assets/fonts`, подключаются в `src/theme/fonts.ts`.

| Назначение | Шрифт | Как задаётся |
|---|---|---|
| Основной текст, подписи, кнопки | **Inter** 400 / 500 / 600 / 700 | `fontWeight` в стиле |
| Крупные заголовки и числа (размер ≥ 24 и вес ≥ 700) | **Mont Black** | автоматически |

Выбор шрифта делает компонент `Text`/`TextInput` из `src/components/Text.tsx`. **Всегда импортируй `Text` оттуда, а не
из `react-native`**: системный `Text` рисует системным шрифтом и выбивается из дизайна (так было на экранах «Материалы»).

Шкала размеров (`font.size`): `xs 11`, `sm 12`, `base 14`, `md 15`, `lg 18`, `xl 22`, `xxl 28`, `display 36`.
Типичное применение: заголовок экрана 26/800, заголовок карточки 15–16/800, основной текст 14, подпись 12–13.
**Минимум для любого текста 12** (время сообщения, счётчики, бейджи): в экранах не осталось значений меньше 12.
Значок `xs 11` в токене оставлен только для совместимости, в новых стилях не использовать.

## 3. Форма и отступы

- Радиусы: `radius.sm 10`, `md 14`, `lg 20`, `xl 28`, `pill 999`. Карточки 22–26, большая карточка «Сейчас» 26,
  кнопки 15–18, поля 14–16.
- Отступы экрана 16; между карточками 10–12; внутри карточки 14–18. Шаг сетки 4.
- Минимальная цель касания 44 dp: если значок меньше, ставь `hitSlop` (на 36-пиксельных кнопках уже стоит 10–12).
- Тени: `shadow.sm` / `md` для стеклянных (полупрозрачных) карточек (без `elevation`: на Android тень просвечивает
  серым прямоугольником), `shadow.lg` (с `elevation`) только для плотных блоков: градиентные карточки, главные кнопки.

## 5. Состояния экрана (обязательные)

Каждый экран с данными показывает все четыре состояния:
1. **Загрузка** — `Skeleton`/`HomeSkeleton`/`SkeletonList`, не пустой экран.
2. **Пусто** — `EmptyState` с понятной подсказкой, что сделать.
3. **Ошибка** — `notifyError(e, { fallback, retry })` (плашка с кнопкой «Повторить»). `Alert.alert` для ошибок не
   использовать; `Alert` оставлен только для подтверждения необратимых действий (удалить, выйти).
4. **Успех** — `notify.success(...)` для действий без видимого результата на экране.

Проверка формы: `notify.fail(заголовок, текст)`.

## 6. Тема и стили

- Стили: `themedStyles(() => ({ … }))` (а не `StyleSheet.create`): иначе цвета запоминаются при запуске и не меняются
  при переключении темы. Значения вне стилей: `themedValue(() => …)`, читать как `NAME()`.
- Смена темы перемонтирует дерево (`App.tsx`), поэтому хуки на тему не нужны.
- Нижние кнопки на экранах во вкладках (`position: 'absolute'`): `bottom = useTabBarSpace() + 12`, иначе плавающая
  панель закроет кнопку.
- Клавиатура: `KeyboardAvoidingView behavior="padding"` на обеих платформах (включён edge-to-edge).
- Не задавай процентные размеры (`'100%'`) абсолютным элементам внутри блока с `padding`: в React Native они считаются
  от внутренней области и получаются меньше блока (так градиент карточки «Сейчас» не доходил до края).

## 6a. Размеры и вёрстка для разных телефонов

- Ширину считай от родителя (`flex`), а не от `Dimensions`; фиксированные ширины только у значков и аватаров.
- Длинный текст: `numberOfLines` и `flex: 1` у строки рядом со значком; заголовки на русском и таджикском бывают
  на 30–40% длиннее английских, проверяй на самых длинных подписях.
- Названия классов не рвать пробелом («5 В»): неразрывный пробел ` `.

## 7. Язык

Три языка: русский (исходный), английский, таджикский. Весь текст интерфейса идёт через `uiText("Русский текст")`
(`{0}`, `{1}` — подстановки), статические списки через `localizeCopy([...])`. Перевод хранится в
`src/i18n/messages.json`; он должен быть **равен** `src/i18n/uiMessages.json` в веб-части (это проверяет тест
`src/i18n/uiText.test.ts`). Имена, названия классов и пользовательский текст не переводятся.
Подписи в `api/*` и `lib/*`, которые попадают на экран, тоже через `uiText`, а не строкой.

## 8. Доступность

- У кнопок без текста (значок) — `accessibilityRole="button"` и `accessibilityLabel`.
- У переключателей: `accessibilityRole="tablist"` / `"tab"` и `accessibilityState={{ selected }}`.
- Индикаторы загрузки: `accessibilityRole="progressbar"` (уже есть в `Skeleton`).

## 9. Что не доделано в дизайне (решения владельца продукта)

См. итоговый отчёт аудита в заметках сессии: отсутствие экрана «история посещаемости» у родителя, нет
экрана настроек уведомлений по типам, `BottomModal` не поднимает форму над клавиатурой на Android, часть экранов
директора (расходы, собрания, ученики) имеют собственную верхнюю панель вместо `StackHeader`.
